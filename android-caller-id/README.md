# НашДом — определитель звонков Android

Разработка ведётся отдельно от рабочей PWA в ветке `feature/android-caller-id`.

## Цель
При входящем звонке с номера, который встречается в CRM, показывать адрес, квартиру, имя и краткую историю обращения **без записи номера в телефонные контакты**.

## Техническая схема
- Нативное Android-приложение (Kotlin), отдельное от PWA.
- `CallScreeningService` с ролью `ROLE_CALL_SCREENING` — для входящих номеров, которые Android передаёт службе.
- Не блокировать и не отклонять звонки: только идентификация.
- Локальный кеш соответствий «номер → адреса/квартиры/последняя заявка» для ответа без ожидания сети; синхронизация с защищённым API НашДом.
- Для отображения во время звонка: сначала проверить доступный системный интерфейс Caller ID на конкретном Samsung, затем при необходимости использовать уведомление о звонке с учётом ограничений Android. Не обещать системную подпись в стандартном экране до теста на устройстве.
- При наличии нескольких квартир по одному номеру показывать все соответствия, не перезаписывать их одним контактом.
- Не сохранять номер телефона в адресную книгу.
- Отдельная функция «Последние звонки» потребует разрешения `READ_CALL_LOG` и проверки политики Android/Google Play. Не смешивать её с ролью Caller ID.

## Безопасность
- Не вшивать `API_SECRET` CRM в APK.
- Добавить отдельную авторизацию устройства с возможностью отзыва.
- API возвращает минимум нужных полей и не предоставляет публичный поиск по номерам.
- Кеш телефона хранить в зашифрованном локальном хранилище, не записывать телефонные номера в логи.
- Звонки от неизвестных номеров не блокировать.

## Первый тест
1. Собрать APK в Android Studio.
2. Установить на Samsung и выбрать НашДом как приложение определения номера.
3. Проверить, вызывается ли служба при звонке с тестового номера.
4. Проверить показ данных при заблокированном экране, выключенном интернете и при повторном звонке.
5. Только после проверки подключить к рабочему серверу.
